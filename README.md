# dda_creater
# 数码宝贝：数字大冒险（DDA v1.4）角色创建器

一个纯前端的网页角色创建工具，支持创建**人类角色**和**数码兽角色**，自动计算衍生属性，并可导出为 **TXT / Excel**，或通过浏览器 **打印 / 另存为 PDF** 生成排版好的双页角色卡。

> 规则数据来源：《数码宝贝：数字大冒险》（Digimon: Digital Adventures）v1.4 中文版规则书。

---

## ✨ 功能特性

- **人类 & 数码兽分页创建**：两个独立 Tab，互不干扰
- **战役等级选择**：标准 / 强化 / 极端，自动调整 CP、属性/技能上限与年龄范围
- **实时衍生属性计算**：伤口格、速度、精准池、闪避池、护甲、伤害（人类）；伤口格、头脑、体能、敏捷、移动、射程、有效极限、BIT/CPU/RAM（数码兽）
- **完整规则校验**：CP/DP 超支检测、属性/技能上限提示、折磨格数限制、特质前置条件与互斥判断、负面特质阶段上限、免费特质唯一性等
- **折磨系统**：轻微/严重/可怕三种折磨，点击格子划掉，自动计入 CP 消耗
- **面向（Aspects）**：主要（+/-4）与次要（+/-2）面向及描述
- **特质树**：约 150 项特质，按 23 个分组展示，支持前置解锁、等级购买、免费首级、负面特质 DP 返还
- **攻击编辑**：阶段决定攻击数量，可为每项攻击挂载 [冲锋][破甲][必中][武器][招牌招式][反击][强力一击] 及效果/范围标签
- **多种导出**：TXT 纯文本 / Excel 双工作表 / 浏览器打印为 PDF

## 📖 使用指南

### 1. 创建人类角色

1. 切换到「🧑 人类角色」Tab
2. **选择战役等级**（标准 30CP / 强化 40CP / 极端 50CP）
3. 填写基本信息（姓名、性别、年龄、搭档、背景）
4. **分配属性**：5 项属性（敏捷/体能/魅力/智力/意志力），每点 1 CP
5. **分配技能**：15 项技能（每个属性 3 项），每点 1 CP
6. **添加折磨**：点击「＋ 轻微/严重/可怕折磨」，填写描述，点击小格子划掉（划掉的花费计入 CP）
7. **填写面向**：主要（+/-4）与次要（+/-2）面向及描述

> 右侧摘要实时显示：剩余 CP、属性/技能投入、灵感上限、衍生属性、已解锁特别指令与规则校验提示。

### 2. 创建数码兽角色

1. 切换到「🐉 数码兽角色」Tab
2. 选择**进化阶段**（幼生期→究极体+）与**体型**
3. 填写名称、属性（疫苗/数据/病毒）、领域、科属/类型
4. **分配 5 项属性**：精准/伤害/闪避/护甲/生命，每点 1 DP（购买特质前每个属性至少 1 点）
5. **购买特质**：按分组展开，勾选即购买；有前置的特质会自动禁用直到满足条件；可多次购买的特质用 ＋/− 调整等级；负面特质返还 DP
6. **编辑攻击**：为每项攻击命名，选择近战/远程与伤害/支援模式，挂载已购标签

> 右侧摘要实时显示：剩余 DP、属性投入/特质投入/负面返还、属性、衍生属性、BIT/CPU/RAM 特化值与规则校验。

### 3. 导出 / 打印

| 操作 | 说明 |
|------|------|
| 🖨 **打印 / 另存为 PDF** | 调起浏览器打印对话框，选择「另存为 PDF」即可生成双页 A4 角色卡（人类 1 页 + 数码兽 1 页），界面控件自动隐藏，排版整洁 |
| 📊 **导出 Excel** | 生成 `.xlsx` 文件，含「人类角色」「数码兽」两个工作表（需联网加载 SheetJS） |
| 📝 **导出 TXT** | 生成纯文本 `.txt` 角色卡，完整包含两侧全部内容 |
| ↺ **重置全部** | 清空当前所有角色数据（有确认提示） |

> 提示：在打印对话框中可关闭「页眉和页脚」获得更干净的输出。

## 🧮 衍生属性公式速查

**人类**（体能 Body、耐力 Endurance、敏捷 Agility、战斗 Fight、闪避 Dodge、生存 Survival、意志力 Willpower）

| 衍生属性 | 公式 |
|----------|------|
| 伤口格 | `max(2, 体能 + 耐力)` |
| 速度/移动 | `敏捷 + 生存` |
| 精准池 | `敏捷 + 战斗` |
| 闪避池 | `敏捷 + 闪避` |
| 护甲 | `体能 + 耐力` |
| 伤害 | `体能 + 战斗` |

> 为 0 的技能在检定时获得 -1 修正（精准池/闪避池已自动计入）。

**数码兽**（精准 Accuracy、生命 Health、伤害 Damage、护甲 Armor、闪避 Dodge）

| 衍生属性 | 公式 |
|----------|------|
| 伤口格 | `生命 + 阶段伤口格` |
| 头脑 | `floor(精准/2) + 阶段头脑` |
| 体能 | `floor((生命+伤害+护甲)/3) + 体型修正` |
| 敏捷 | `floor((精准+闪避)/2) + 体型修正` |
| BIT / CPU / RAM | `floor(对应属性/10) + 阶段加成 + 特化值` |
| 移动 | `阶段基础移动 + 修正` |
| 射程 | `floor((精准+头脑)/2) + BIT` |
| 有效极限 | `floor(精准/2) + 头脑 + BIT` |

> 验证示例：多拉兽（成长期/中型）精准 5、伤害 3、闪避 3、护甲 5、生命 5 → 伤口格 7 / 头脑 5 / 体能 4 / 敏捷 4 / BIT 1 / CPU 1 / RAM 1 / 移动 6 / 射程 6 / 有效极限 8 ✓

## ⚠️ 注意事项

- **Excel 导出**依赖 SheetJS CDN（`cdn.sheetjs.com`），首次导出需联网；离线时可用 TXT 或打印替代
- 浏览器 `file://` 直接打开即可运行；若部分浏览器拦截本地下载，请改用本地服务器方式
- 打印/另存 PDF 时建议在打印对话框中关闭「页眉和页脚」
- 数值校验逻辑仅提供提示，不强制阻止（GM 可自行裁定特殊案例，如爆发力量等需 GM 批准的特质）

## 🔧 自定义 / 扩展

- 修改战役等级数值、新增特质：编辑 `data.js` 中的对应常量
- 特质字段：`id`（唯一）、`group`（分组）、`name`、`dp`（消耗，负数=返还）、`cat`（S/T/A 类型）、`rank`（可购等级）、`prereq`（前置 id 数组）、`exclusive`（互斥 id 数组）、`stageMin`（最低阶段）、`freeFirst`（首级免费）、`mods`（属性修正）
- 界面与逻辑：`index.html` 内联 JS，核心状态在 `S` 对象中
